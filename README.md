# job-digest (Claude Code plugin, starter)

Weekly job search, fit scoring and repeat-tracking driven by a personal profile.md.

## Use locally
1. Open this folder in VS Code with the Claude Code extension.
2. Create a separate working folder with your profile.md (from templates/) and run `/job-digest`.
