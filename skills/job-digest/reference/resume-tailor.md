# Resume tailoring — core rules

**Philosophy:** you're not lying or fabricating — you're highlighting the parts of a true record that fit this role. Reordering and emphasis, never invention.

1. Rewrite the professional summary to mirror the target role's title and its top 2-3 stated requirements.
2. Reorder the skills list so the JD's most-emphasized skills come first; add real keywords from the JD that the person's actual experience supports — never ones it doesn't.
3. Reorder experience entries if an older role is more relevant than the most recent one — but keep every real job, employer, title, and date range; never delete one.
4. Within each role, lead with whichever existing bullet is most relevant to this JD; reword bullets toward the JD's own terminology only where that terminology is already true of the work described.
5. Keyword rule: use real JD language naturally, in more than one section, without repeating a term artificially or changing what a bullet actually claims.
6. The line: reordering, emphasis, terminology-matching, and elaborating a vague bullet with real detail already present elsewhere in the CV are all fine. Invented skills, changed numbers, fictional roles/titles, and unearned certifications are not — ever.
