# Resume formatting — ATS-safe rules

- **Page length — hard cap: 2 pages, no matter how senior the candidate or how long their history.** Do not use 3 pages even for a 15+ year / executive-level candidate. If the full real history doesn't fit in 2 pages at the spacing below, compress older/less-relevant roles into shorter entries (title, employer, dates, one line) rather than letting the page count grow — never drop a real role or date entirely, only shorten its presentation.
- **Professional summary — hard cap: 3-4 lines, 2-3 sentences.** This is not the place for a full career narrative; it's a hook. If a draft summary runs longer, cut it down before moving on, don't let it stay as a dense paragraph.
- **Margins**: 0.6"-0.7" on all sides (toward the tighter end of the acceptable 0.5"-1" range, specifically to help hit the 2-page cap above).
- **Fonts**: Arial, Calibri, Helvetica, Verdana, Times New Roman, Georgia, or Garamond only. Name 16-18pt, section headers 11-12pt, body and bullets 10-10.5pt — use the smaller end of each range, not the larger, to help hit the 2-page cap.
- **Bullet spacing/indent — this is usually where a resume silently bloats past 2 pages:** hanging indent of 0.15"-0.2" (not Word's default list-style indent, which often runs 0.3"-0.5" and visibly wastes horizontal space — set it explicitly, don't accept a default). Line spacing 1.0 (single). Space after each bullet paragraph: 0-2pt, not a full blank-line gap. Space after each role's bullet block, before the next role: 6-8pt, not more.
- **Section order**: Contact info → Professional Summary → Skills → Professional Experience → Education → Certifications → Additional (volunteer, languages, etc.).
- **Bullets**: 3-6 per role for recent/relevant roles; 1-2 for older/less-relevant ones consolidated per the page-length rule above. Each bullet 1-2 lines, starts with an action verb, ends with a result.
- **Dates**: one consistent format throughout (e.g. "Jan 2020 - Present").
- **Contact info**: name, professional email, phone, city/state, LinkedIn — no full street address, photo, or birth date.

DO: standard fonts; simple bullets (•, -, *); bold/italic used sparingly; contact info in the document body, never only in a header/footer; single-column layout; consistent formatting throughout; explicitly set paragraph/indent spacing rather than accepting Word's/python-docx's default list style.

DON'T: tables (beyond a simple contact-info one), text boxes, multi-column layouts, headers/footers carrying essential info, images or graphics, decorative/unusual fonts, skill-level bars, emojis or special characters, color carrying meaning that plain text doesn't also carry, a professional summary longer than 4 lines, a document longer than 2 pages.
